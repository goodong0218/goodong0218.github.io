覆盖而不是 fork

Stack 的样式变量集中在 themes/stack/assets/scss/variables.scss，但不要直接改主题文件——升级主题时会全部丢失。

Hugo 的 asset 查找顺序里，站点根目录的 assets/ 优先于主题的。所以新建：

assets/scss/custom.scss

这个文件会被主题的 style.scss 自动 @import，是最干净的入口。

改哪几个变量 

:root {
    --accent-color: #b8862f;
    --accent-color-darker: #96691f;
    --accent-color-text: #fff;

    --body-background: #faf9f7;
    --card-background: #fff;

    --card-text-color-main: #1b1c1e;
    --card-text-color-secondary: #55585d;

    --sys-font-family: -apple-system, BlinkMacSystemFont, "Segoe UI",
        "PingFang SC", "Microsoft YaHei", sans-serif;
    --base-font-family: var(--sys-font-family);

    --card-border-radius: 12px;
    --tag-border-radius: 999px;
}

亮暗两套要分别写，暗色的选择器是 [data-scheme="dark"]：

[data-scheme="dark"] {
    --accent-color: #d9a441;
    --accent-color-darker: #e8bc6a;
    --accent-color-text: #16181a;

    --body-background: #17191b;
    --card-background: #1f2225;
    --card-text-color-main: #eceef0;
}

标题用衬线

正文用无衬线读起来更快，但中文标题用衬线会明显更有「文章」的气质：

@font-face {
    font-family: "Noto Serif SC";
    src: url("/fonts/NotoSerifSC-subset.woff2") format("woff2");
    font-display: swap;
    unicode-range: U+4E00-9FFF, U+3000-303F, U+FF00-FFEF;
}

.article-title,
.article-subtitle,
.section-title,
.site-name {
    font-family: "Noto Serif SC", "Songti SC", "SimSun", Georgia, serif;
    letter-spacing: 0.01em;
}

unicode-range 很关键：中文子集字体动辄几 MB，只声明中文区间，命中时才请求，西文继续走系统字体。

强调色的来源

选琥珀金（#b8862f）是从博客封面图里取的色——那张幽暗森林的金色光晕。强调色从站点自己的图片里取，比凭空挑一个品牌色更容易自成一套。

检查清单

  • 亮色下正文对比度 ≥ 4.5:1；
  • 暗色下卡片背景与页面背景要拉开层次，但差值不要超过 20%；
  • 代码块用固定的深色底，不要跟着亮色模式变白——否则语法高亮配色会失效。
