Nginx 核心配置实验

⚙️ 实验前准备（目录与结构说明）

  1. 您的 /etc/nginx/nginx.conf 中 http 块必须包含以下两行（通常默认就有）：
    include /etc/nginx/conf.d/*.conf;          # 用于加载独立的内部后端 server 块
# ... 您的 8080 server 块内部 ...
include /etc/nginx/default.d/*.conf;       # 用于加载注入到 8080 的 location 规则
  2. 外部防火墙仅放行 8080 端口。
  3. 每次修改完配置，务必执行 nginx -t 检查语法，然后执行 nginx -s reload 重载。

🧪 实验一：基础配置（路径映射与错误页）

1. 准备测试文件

mkdir -p /var/www/exp1/siteA /var/www/exp1/siteB /var/www/exp1/files
echo "<h1>这是站点 A 的页面</h1>" > /var/www/exp1/siteA/index.html
echo "<h1>这是站点 B 的页面</h1>" > /var/www/exp1/siteB/index.html
echo "这是一个测试文件" > /var/www/exp1/files/test.txt

2. 编写独立配置 新建 /etc/nginx/default.d/exp1_locations.conf：

# 覆盖主配置的默认根目录（如果访问 IP:8080/ 默认去这里找）
location /siteA/ {
    root /var/www/exp1;  # 实际拼接为 /var/www/exp1/siteA/
    index index.html;
}

# 路径映射：访问 /siteB/ 时去 /var/www/exp1/siteB 找文件
location /siteB/ {
    root /var/www/exp1;  # 实际拼接为 /var/www/exp1/siteB/
    index index.html;
}

# 开启目录浏览：访问 /files/
location /files/ {
    root /var/www/exp1;  # 实际拼接为 /var/www/exp1/files/
    autoindex on;
}
charset utf-8; # 解决中文乱码

3. 验证步骤

  • 访问 http://服务器IP:8080/siteB/ -> 看到站点 A主页。
  • 访问 http://服务器IP:8080/siteB/ -> 看到站点 B 页面。
  • 访问 http://服务器IP:8080/files/ -> 看到目录列表。
  • 访问 http://服务器IP:8080/notexist -> 看到404 页面。

🛡️ 实验二：访问控制（IP 限制 + Basic 认证）

1. 准备测试文件与密码

mkdir -p /var/www/exp2/admin /var/www/exp2/secret
echo "<h1>欢迎来到管理员后台</h1>" > /var/www/exp2/admin/index.html
echo "<h1>这是机密数据</h1>" > /var/www/exp2/secret/index.html

# 创建账号密码文件，用户名为 teacher，按提示输入两次密码 (如: 123456)
mkdir -p /etc/nginx/auth
htpasswd -c -m /etc/nginx/auth/.htpasswd teacher

2. 编写独立配置 新建 /etc/nginx/default.d/exp2_locations.conf：

# 1. IP 访问控制：仅允许本机访问 /admin/
location /admin/ {
    root /var/www/exp2;               # 指向对应的本地目录
    index index.html; 
    allow 127.0.0.1;                  # 仅允许本机 IP
    deny all;                         # 拒绝其他所有 IP（返回 403）
}

# 2. 账号密码认证：保护 /secret/
location /secret/ {
    root /var/www/exp2;
    index index.html; 
    auth_basic "Restricted Area";     # 浏览器弹窗的提示语
    auth_basic_user_file /etc/nginx/auth/.htpasswd; # 指向密码文件
}

3. 验证步骤

  • 在服务器本机执行 curl http://127.0.0.1:8080/admin/ -> 正常显示。
  • 在电脑浏览器输入 http://服务器IP:8080/admin/ -> 返回 403 Forbidden。
  • 浏览器访问 http://服务器IP:8080/secret/ -> 弹出密码框，输入 teacher/123456 才能看到页面。

🔄 实验三：反向代理

1. 准备模拟后端

mkdir -p /var/www/backend
echo "<h1>我是内部隐藏的后端服务器 (8081)</h1><p>你通过 Nginx 的 8080 代理访问到了我。</p>" > /var/www/backend/index.html

2. 编写配置（需要两个文件） 首先，定义内部后端服务器。新建 /etc/nginx/conf.d/exp3_backend.conf（加载到全局 http 块）：

server {
    listen 127.0.0.1:8081;            # 仅监听本地回环地址，外部无法直接访问
    root /var/www/backend;
    index index.html;
}

其次，配置代理规则。新建 /etc/nginx/default.d/exp3_proxy.conf（注入到 8080）：

# 当访问 /proxy/ 时，转发给内部的 8081 后端
location /proxy/ {
    # 结尾的 / 表示将 /proxy/ 替换为 / 发给后端
    proxy_pass http://127.0.0.1:8081/; 
    
    # 传递客户端真实信息给后端
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}

3. 验证步骤

  • 浏览器访问 http://服务器IP:8080/proxy/ -> 看到“我是内部隐藏的后端服务器”。
  • 可以尝试在服务器本机访问 http://127.0.0.1:8081/（能访问），但在自己电脑上用 http://服务器IP:8081/（应该被拒绝或超时），体现反向代理的安全性。

⚖️ 实验四：负载均衡

1. 准备两个“模拟后端”

mkdir -p /var/www/node1 /var/www/node2
echo "<h1 style='color:red'>我是节点 1 (Node A)</h1>" > /var/www/node1/index.html
echo "<h1 style='color:blue'>我是节点 2 (Node B)</h1>" > /var/www/node2/index.html

2. 编写配置（需要两个文件） 首先，定义后端池和节点。新建 /etc/nginx/conf.d/exp4_backend.conf：

# 定义后端服务器池（默认轮询）
upstream backend_servers {
    server 127.0.0.1:8082;            # 节点 1
    server 127.0.0.1:8083;            # 节点 2
}

# 模拟节点1 (仅内部访问)
server {
    listen 127.0.0.1:8082;
    root /var/www/node1;
    index index.html;
}

# 模拟节点2 (仅内部访问)
server {
    listen 127.0.0.1:8083;
    root /var/www/node2;
    index index.html;
}

其次，配置负载均衡入口。新建 /etc/nginx/default.d/exp4_lb.conf：

# 当访问 /lb/ 时，请求被代理到 upstream 池
location /lb/ {
    proxy_pass http://backend_servers/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}

3. 验证步骤

  • 在浏览器中访问 http://服务器IP:8080/lb/（建议使用无痕模式）。
  • 多次刷新页面，会交替出现“我是节点 1（红色）”和“我是节点 2（蓝色）”。
  • 进阶：尝试在 upstream 里的 server 127.0.0.1:8082; 后面加上 weight=2;，再次刷新观察分配比例的变化。
