# public 目录说明

> 这里是**网站成品**：Hugo 把你写的 Markdown、配置、样式编译出来的静态网页。
> 整个文件夹上传到任何静态服务器（GitHub Pages、Cloudflare Pages、虚拟主机…）就能访问。

## 先记住一条

**`public/` 里的东西不要手动改。**

它每次「生成网页」都会重新生成，你手改的内容会被覆盖。
要改内容 → 去 `blog-hugo/content/`；要改样式 → 去 `blog-hugo/assets/`；然后重新构建。

---

## 根目录文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | **首页**，文章列表第一页 |
| `404.html` | 找不到页面时的错误页 |
| `index.xml` | RSS 订阅源（`/index.xml`） |
| `sitemap.xml` | 站点地图，给搜索引擎爬虫用 |

## 文件夹

| 文件夹 | 作用 | 源文件对应 |
| --- | --- | --- |
| `p/` | **每篇文章一个文件夹**，`p/<slug>/index.html` 是文章正文，同目录还有这篇文章用到的图片 | `content/post/<目录>/` |
| `about/` | 关于我页面 | `content/page/about/` |
| `links/` | 友情链接页面 | `content/page/links/` |
| `archives/` | 归档页，按年份列出所有文章 | `content/page/archives/` |
| `search/` | 搜索页，`index.json` 是搜索用的全文索引 | `content/page/search/` |
| `categories/` | 每个分类一个子目录（如 `tech/`、`daily/`），子目录里的 `page/` 是分页 | `content/categories/` |
| `tags/` | 每个标签一个子目录，`page/` 是分页 | 由文章 front matter 的 `tags` 自动生成 |
| `post/` | 原始文章小节（`/post/`），一般用不到；`pinned/` 是置顶公告 | `content/post/` |
| `page/` | 固定页小节（`/page/`）及其分页 | `content/page/` |
| `img/` | 头像、封面等图片 | `blog-hugo/static/img/` 与 `assets/img/` |
| `scss/` | 编译、压缩后的 **CSS 样式表**（文件名带哈希）。多个并存是历史版本，页面只引用最新的那个 | `assets/scss/` |
| `ts/` | 编译后的 **JavaScript**（菜单、暗色模式、代码复制、搜索等） | `assets/ts/` |

## 两类路径的区别

- `/p/<slug>/` —— 文章（`[permalinks] post = "/p/:slug/"`）
- `/categories/tech/`、`/tags/css/` —— 分类页和标签页（用 `slug`，不是中文名）

## 想改网站时去哪改

| 想改 | 改这里 | 编辑器里的位置 |
| --- | --- | --- |
| 文章 | `content/post/<目录>/index.md` | 文章 |
| 关于我 / 友链 / 归档 | `content/page/*/index.md` | 外观 → 关于我 / 友情链接 / 归档 |
| 分类 | `content/categories/<名字>/_index.md` | 外观 → 归档 → 分类管理 |
| 站名、侧栏、图标 | `config/_default/*.toml` | 外观 → 页面外观 |
| 颜色、字体、间距 | `assets/scss/custom.scss` | 外观 → 页面外观，或「文件」页直接改 |

改完点「构建与预览 → 生成网页」，`public/` 会重新生成。
